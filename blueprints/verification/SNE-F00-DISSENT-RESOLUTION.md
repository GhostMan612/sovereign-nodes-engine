# F-00 — Independent dissent and discrepancy arbitration

## Response classes

| Class | Examples | Appropriate next action |
|---|---|---|
| `SUPPORTED-SOURCE-ONLY` | matching pinned CMake option or MAPINFO declaration | retain source finding; game build stays NOT RUN |
| `CORRECTION-REQUIRED` | wrong blob, line, path, option default | append exact correction and impacted claim IDs |
| `DISPUTED` | alternate parser behavior with credible source evidence | preserve both explanations and assign discriminating primary-source review |
| `REQUIRES-RUNTIME` | whether long frames render, boolean ToInt, GLDEFS emits light | leave G3/G6 open; future operator-approved synthetic experiment |
| `INVALID-EVIDENCE` | current branch substituted for pin, unmodified PK3 assumed but patched, bogus screenshots | reject claimed proof, no gate promotion |
| `OUT-OF-SCOPE` | upstream engine PR, current dependency download or full GPU benchmark | route to later authorized work order |

## Adjudication rule

The author never closes objections raised by an independent reviewer alone. Reviewer records evidence and disagreement; operator records decision, accepted corrections or explicit unresolved risk. Disputed P0 claims block G1; absent distinct reviewer blocks G7. Missing G2/G3/G4/G5/G6 means ADR-SNE-002 stays HOLD even if every P0 source claim is independently supported.

## Prioritization

Stop first on: wrong game map identity, missing source path, false assertion about handoff behavior, sprite parser overclaim, licensed asset inclusion, fabricated test results, unapproved local command execution. Record follow-on question and next responsible role for each.
