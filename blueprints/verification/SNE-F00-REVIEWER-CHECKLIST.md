# F-00 — Independent reviewer operator checklist

**All boxes intentionally unchecked.** The package author may not mark them completed.

- [ ] Reviewer identity/qualification and independence from research author validated privately.
- [ ] Operator authorizes exact read-only repositories/revisions/retention/scope; no local experiments authorized implicitly.
- [ ] Git commits and blobs independently verified for all P0 claims F00-C01..C11.
- [ ] MAPINFO/GLDEFS/actor sprite names and GZDoom parser independently cross-read, with a counterclaim considered.
- [ ] `fps_launcher.gd` boolean serialization and `sn_handoff.zs` `ScanRaw`/`ScanInt` traced; exact `ToInt` semantics not invented.
- [ ] `validate_pk3.py` full pinned Git tree checked; actual packager/validator path and comment status adjudicated.
- [ ] GZDoom/UZDoom/BiasedDoom root CMake claims sampled; feature flags not confused with a compiled executable.
- [ ] UZDoom upstream AI PR restrictions distinguished from downstream GPL and asset-rights obligations.
- [ ] One sample or high-risk claim from each older A–F package checked against original evidence, with limitations disclosed.
- [ ] Counterevidence, reviewer dissent and issues recorded in structured templates.
- [ ] No raw private data, commercial IWADs or device credentials entered public repository.
- [ ] Operator disposition or HOLD recorded; G2–G6 remain NOT RUN/NOT CLEARED unless **separate real evidence** exists.
- [ ] Independent G7 signature/decision explicitly recorded; ADR still HOLD until all other gates close.

If any check is incomplete, record it as such. Reading this checklist or filling example JSON is not independent review completion.
