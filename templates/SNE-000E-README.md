# WO-E review and future execution templates

All JSON documents in this folder are **blank planning records**. Fields remain `null`, arrays empty, status `NOT_RUN` or `PENDING`. Do not fill them with invented results. Completed records with sensitive identities or local paths stay outside Git or are sanitized before publication.

- `SNE-000E-REVIEW-RECORD.json`: real independent reviewer scope, dissent and signoff.
- `SNE-000E-ADR-VOTE.json`: operator choice and evidence-backed scores (currently absent).
- `SNE-000E-COMPAT-PROOF.json`: one candidate/case/fixture source+binary test proof.
- `SNE-000E-GATE-STATE.json`: explicit G1–G8 pending gate model and decisions.

No template authorizes compiling, installing dependencies, game launching, data bridging, source repo patching or Git pushes.
