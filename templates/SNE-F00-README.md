# F-00 — Blank future review records

- `SNE-F00-CLAIM-REVIEW.json`: **one per independently reviewed claim**; source-only proof must not imply runtime PASS.
- `SNE-F00-INDEPENDENT-REVIEW.json`: reviewer appointment, coverage, conflicts/dissent and signatures. It defaults `NOT REVIEWED` and G1/G7 OPEN.
- `SNE-F00-ISSUE-RECORD.json`: incorrect claim, counterevidence, severity, adjudication and an immutable affected-gate trail.
- `SNE-F00-OPERATOR-DECISION.json`: explicit source-review documentary acceptance and independent distinction; all implementation/test permissions default FALSE.

These are templates, not filled-in review results. Store private signatures and personal identifiers off-repo; publish only sanitized references under operator-controlled source rights. No template grants any actual authorization.
